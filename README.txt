TRAILREELS FULL PREVIEW

This is a bigger visual preview of TrailReels.

It includes:
- Feed
- Reels
- YouTube-style Trails
- Memories page
- Archive page
- Reelers page
- Profile page
- Login demo
- Owner panel
- Report inbox
- Badge manager
- Creator-type badges around profile pictures
- Owner crown and admin hammer
- Animated play/pause overlay
- Phone-install PWA setup

HOW TO TEST LOCALLY:
1. Extract the ZIP.
2. Open a terminal in the folder.
3. Run: npm install
4. Run: npm run dev

HOW TO DEPLOY TO NETLIFY:
1. Upload the folder to GitHub.
2. Import the GitHub repo into Netlify.
3. Build command: npm run build
4. Publish folder: dist

HOW TO INSTALL ON PHONE:
After deploying, open the Netlify link.
Android Chrome: menu -> Add to Home Screen / Install app
iPhone Safari: share button -> Add to Home Screen

SUPABASE NOTE:
This preview uses demo/local data first.
Supabase can be added later for real global accounts, reels, reports, and owner roles.
